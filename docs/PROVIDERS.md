# Источники данных и адаптеры

## Текущая реализация

`DemoMarketplaceProvider` использует `Back/src/providers/catalog.js` и `simulatedParser.js`. В fixtures представлены три условных формата ответов; парсер нормализует их в единую модель товара. Это синтетический каталог, созданный для проверки UI, фильтров, сортировки, пагинации и сохранения истории. Все возвращаемые карточки имеют `source: "synthetic-demo"`; в интерфейсе они помечены DEMO.

## Контракт адаптера

Адаптер должен реализовать метод:

```js
async search(filters) {
  return {
    items: [],
    total: 0,
    page: filters.page,
    limit: filters.limit,
    totalPages: 0,
    source: 'provider-name'
  };
}
```

Единая модель товара:

```js
{
  id: 'provider:item-id',
  marketplace: 'Provider Name',
  title: 'Product title',
  brand: 'Brand',
  price: 1234,
  oldPrice: 1500,
  rating: 4.5,
  reviewCount: 100,
  inStock: true,
  category: 'Category',
  description: 'Short description',
  source: 'provider-name'
}
```

## Подключение реального источника

Перед реализацией:

1. Изучить актуальные правила и документацию площадки.
2. Проверить, разрешает ли используемый API публичный поиск и какие права/ключи нужны.
3. Хранить ключи только в переменных окружения/secret manager.
4. Соблюдать rate limits, квоты, требования к атрибуции и хранению данных.
5. Реализовать таймауты, ограниченные повторы с backoff и нормализацию ошибок.
6. Не обходить CAPTCHA, авторизацию, антибот-защиту или технические ограничения.
7. Добавить контрактные тесты адаптера и тесты на недоступность/ограничение источника.

Никаких live-подключений к Wildberries, Ozon или Яндекс Маркет в этой версии нет. Упоминания этих площадок в демонстрационном каталоге не означают, что данные получены от них.
