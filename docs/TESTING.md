# Тестирование

## Unit tests

Из каталога `Back`:

```bash
npm test
```

Тесты используют встроенный Node.js test runner и проверяют:

- наличие и маркировку синтетических demo-данных;
- фильтрацию по маркетплейсу и запросу;
- диапазон цен и наличие;
- сортировку и пагинацию;
- валидацию регистрации, входа и диапазона цен.

## Syntax check

```bash
npm run check
```

## Ручной smoke test

1. Запустить приложение через Docker Compose.
2. Открыть `/api/health` — ожидать `status: ok` и `database: ok`.
3. Зарегистрировать тестового пользователя.
4. Найти товар по слову `наушники`.
5. Применить фильтр площадки и диапазон цены.
6. Открыть историю, повторить запрос, удалить одну запись.
7. Очистить историю и выйти из аккаунта.
8. Войти снова и проверить, что история действительно принадлежит аккаунту.

Интеграционные тесты HTTP API и тесты PostgreSQL следует добавить перед production-релизом.
