# Состав полного архива

Этот архив содержит полный full-stack проект, а не только API.

| Папка | Что содержит |
|---|---|
| `Front/` | React-приложение: вход/регистрация, поиск, фильтры, карточки товаров, история, CSS, Vite и Nginx |
| `Back/` | Express API, PostgreSQL, сессии, авторизация, демо-провайдеры, тесты |
| `docs/` | Архитектура, API, источники данных, тестирование, безопасность |
| `.github/workflows/` | CI для тестов backend и сборки frontend |

## Важное ограничение

Парсер работает в демонстрационном режиме с локальными синтетическими данными. Интеграции с реальными маркетплейсами не включены. Это явно отражено в интерфейсе и документации.
